# E-commerce Product Analytics

## О проекте

Комплексный проект продуктовой аналитики интернет-магазина на основе реальных событий пользовательского поведения.

**Цель:** исследовать поведение пользователей, оценить конверсию в покупку, выявить закономерности взаимодействия с товарами и сформировать продуктовые гипотезы.

## Датасет

Источник: [Retailrocket E-commerce Dataset](https://www.kaggle.com/datasets/retailrocket/ecommerce-dataset)

Основной файл: `events.csv`

| Показатель | Значение |
|---|---:|
| Количество событий | 2 756 101 |
| Уникальные пользователи | 1 407 580 |
| Уникальные товары | 235 061 |
| Период наблюдения | 03.05.2015–18.09.2015 |
| Типы событий | view, addtocart, transaction |

## Технологии

- **Python:** Pandas, NumPy
- **Визуализация:** Matplotlib
- **SQL:** DuckDB
- **Аналитика:** статистика, когортный анализ, RFM, сегментация, воронки
- **A/B-тестирование:** проверка гипотез, расчёт размера выборки
- **Jupyter Notebook**

## Продуктовые гипотезы

В рамках проекта сформированы и приоритизированы гипотезы:

- Улучшение карточки товара.
- Упрощение процесса оформления заказа.
- Добавление функциональности избранного.
- Улучшение представления товаров.

Для планирования A/B-тестирования рассчитан размер выборки:

- Базовая конверсия: 2.30%.
- Целевая конверсия: 2.53%.
- MDE: 10% относительно базового уровня.
- Уровень значимости: 5%.
- Статистическая мощность: 80%.
- Размер выборки: 69 986 пользователей на группу.

## Ограничения данных

- Нет цен товаров, выручки и маржинальности.
- Нет данных о рекламных расходах и маркетинговых каналах.
- Период наблюдения ограничен 03.05.2015–18.09.2015.
- События покупки не равны уникальным заказам.
- Наблюдаемые зависимости не доказывают причинно-следственные связи.

## Запуск проекта

1. Клонировать репозиторий.
2. Скачать Retailrocket E-commerce Dataset.
3. Поместить `events.csv` в `data/raw/`.
4. Установить зависимости:

```bash
pip install pandas numpy matplotlib duckdb jupyter
```

5. Запустить Jupyter Notebook:

```bash
jupyter notebook
```

6. Выполнять ноутбуки последовательно, начиная с `01_data_quality_analysis.ipynb`.

## Итог

Проект демонстрирует полный цикл продуктовой аналитики интернет-магазина: от проверки качества данных и исследования пользовательского поведения до сегментации, статистического анализа, разработки продуктовых гипотез, SQL-анализа и визуализации результатов.
